# 鲁棒起立过渡教师设计

用户于 2026-10-07 确认执行。本设计取代 bridge v1 的速度/FR 高度驱动任务。

## 目标与范围

三足教师产生不同速度、FR 位置和接触相位的实际状态；FR 命令达到起立边界后锁定过渡控制。过渡策略完成参考引导的起立，允许调整速度、落脚点和中段 FR 误差，最终由冻结双足教师在同一真实状态下验证 2.5 秒。两个教师动作不进入 PPO，交接不清零状态、动作历史或随机化。

## 引导数据

保留原资产。名义起立参考使用 0 到 2.5 秒完整准备、转移和起立过程，终点保持。用每次接管独立的时间和随机播放速度推进，完全不依赖 FR 命令高度。高度相对地面、重力方向、九个支撑关节、FL 相对锚定坐标位置、卸载和接触阶段用于观测/奖励；不奖励绝对 XY、yaw、参考速度或固定后脚世界落点。接管时捕获实际高度、重力、关节和 FL 位置，0.3 秒内平滑衔接参考，仅修改参考。FR 沿已有经检查的路径起终点独立平滑移动，中段误差尺度 0.10 m、末段 0.05 m。

## 控制与鲁棒范围

保留实际源教师前缀和 12 条路径。入口不再要求 FR 误差小于 0.1 m 或理想支撑，只拒绝物理失败。每次尝试随机参考速度 0.85 到 1.15；接管时可按 0.5 概率施加水平速度增量，各轴 ±0.10 m/s、角速度增量各轴 ±0.20 rad/s，保持位置、关节及历史。扰动可关闭做名义基线，不宣称覆盖任意可恢复状态。起立进度和物理状态满足后交接，参考完成不能独立判成功。双足验证默认零速度命令，速度门控启动值 0.5 m/s，须后续校准。

## 奖励与观测

删除线速度/角速度跟踪及全程后髋零角惩罚。奖励高度、重力方向、弱支撑关节、弱 FL 相对位置、低权重 FR、阶段支撑和实际接近终点的增量。保留动作变化、滑移、限位、归一化力矩和碰撞成本。终端定义为测量得到的 ±20 交接结果，不对验证窗口额外折扣；PPO 在过渡步骤内继续 gamma=0.99。观测原 51 维加 22 个引导特征，actor73/critic117；冻结教师仍各自 actor51。初始化将源 actor 首层扩展并将新增通道权重置零，其余均值网络参数原样复制。

## 兼容性与验证

新 bridge_contract v2 包含观测维度、参考/路径/专家哈希、全部新增协议参数、奖励配置和终端语义。旧 bridge v1 checkpoint 必须明确拒绝加载。旧资产和旧任务不改。验证包括时间与 FR 解耦、真实状态/历史连续、入口偏差、部分重置、参考特征可见性、逐项奖励、终端归因、冻结专家不变、PPO 更新和 checkpoint 往返。CPU 实际物理短运行及可用时 GPU 短运行不等于已训练收敛。
