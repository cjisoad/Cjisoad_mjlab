# leg_manip 站立、行走、操作课程

用户已批准执行：第一阶段同时学习四足站立、双足站立和互相切换，第二阶段再加入行走，第三阶段再加入操作。所有双足站立样本的 FR 目标固定为默认双足姿态位置；四足样本采用零目标。不增加 actor 通道，保持 51/131 观测和锚点基座速度的 noisy/exact 对应关系。

第一阶段速度为零，只采样四足零目标与由 DEFAULT_ANGLES / DESIRED_ANGLES 及统一锚点变换推导的默认双足 FR 偏移（约 .133488,.030602,.478042m）。重采样保证两种目标及双向切换都有机会，保持足够的站姿驻留。转换参考平滑变化，终点必须实际站稳，不能只按时间经过判定成功。

第二阶段保留默认站姿与切换，逐步扩大两种模式速度范围，双足侧向命令为零。第二阶段晋级同时验证四足、双足速度跟踪及站姿与切换；第三阶段才启用随机可达 FR 目标，并保留纯站立/行走样本。

固定站姿参考不是随机操作。需要区别 nominal stance 与 active manipulation，恢复非操作时 FR 默认姿态/前腿对称反馈。零速双足鼓励两只后足支撑，后足交替接触与抬脚奖励仅适用于移动。保留已有高度、重力方向、前足离地、站姿高度等约束，增加可在高度门未打开时学习的站立反馈；第一、二阶段 FR 精确跟踪权重降低。真实站姿成功必须检查机体姿态、高度、前后足支撑和速度，不能被 FR 误差小替代。

允许部分训练回合从有效后腿站姿附近初始化以获得双足控制样本；其余从四足起步。完整转换单独统计，最终评估支持全部从正常四足起步。复位必须同步 command 模式/退出宽限状态，避免双足起点被四足倾角终止。

晋级使用固定持续时间窗口、充分样本以及连续多窗口成功，失败也重启窗口时间。分别检查四足站立、双足站立、起立、下降及第二阶段分模式速度，禁止总体平均掩盖双足失败。记录每项判定、样本数、连续成功数。日志拆分 tripod/biped 与 stationary/moving，并记录站姿高度、倾角、支撑及门开启率。

新课程须在 checkpoint 保存明确版本、阶段、窗口起点、连续通过数及课程统计；拒绝将旧课程阶段自动恢复成新阶段。旧的其他任务代码与当前训练快照不修改。用户已有的未提交改动已保存 baseline 快照；开发在独立分支工作区完成，再以校验过的增量同步回共享目录。

验证包括采样阶段、固定目标 FK、双向转换与复位、静止/行走接触奖励、门外站姿反馈、短窗口不能晋级、各模式单独达标、持久化恢复、观测一致性、真实 CPU 步进及 PPO/checkpoint 冒烟。完成后按用户已有服务器授权核实 4090 状态，保留旧 run 与每个权重，启动独立的新课程实验。
