# 键盘并联范围的三教师状态机设计

状态：用户已确认，触发高度0.33m。本文件整理用户指定的“三足接近最高操作高度 → 过渡起立 → 站稳后双足接管”控制流程。

## 1. 接入位置

扩展 `scripts/keyboard_teacher.py`，在 `loco_pedipulation_t --workspace union` 模式接入状态机。增加专用键盘运行模块，复用公共机器人、参考采样、站稳条件及动作坐标转换。原来的键盘单教师模式保留。

采用同一个 MuJoCo 环境内选择三个策略的方案。另建环境后搬运状态需要迁移接触、控制历史和物理参数，复杂且容易引入不连续；直接以高度在三足和双足间切换则无法完成用户要求的过渡起立。

每个环境独立保存状态，不套用批量评估的50/50配额限制；单环境键盘播放可用。

## 2. 状态及触发

### TRIPOD：三足教师控制

- 保持原有 WASD、方向键及 Q/E 操作。
- 高度沿用公共 FR 零点的绝对竖直偏移 `dz`，不是脚的世界坐标高度。
- 默认触发高度为 `TRIPOD_HIGH - 0.02 = 0.33m`；通过命令行提供 margin 参数。
- 三足实际接收的 FR 目标限制在三足操作盒内。键盘请求达到触发高度、三足实际接收目标也达到该高度、FR位置误差小于0.10m且没有物理失败时，连续满足0.10s进入 TRANSITION。
- 触发必须按仿真控制周期计时；暂停、渲染速度和窗口失焦不能推进触发计时。

### TRANSITION：过渡教师控制

- 捕获当时的真实机身状态、关节状态和参考对齐信息，启动参考时钟。
- 保留物理速度、上一动作、动作延迟历史、motor offsets与物理参数；不把机器人写入参考姿态。
- 采用过渡教师的参考引导完成起立。FR轨迹从切换前实际下发目标连续起步，连接到兼容的双足目标；不执行训练流程中的自动三足预热或随机操作前缀。
- 该阶段冻结键盘的速度和FR目标修改，速度命令为零，但不清除机器人已有动量。暂停、复位仍可用。
- 参考完成后，连续满足站稳条件1s才进入 BIPED。包括完整姿态/高度、前脚离地、后脚支撑、线/角速度及关节速度等条件；不单凭机身高度切换。FR误差保留为诊断项及跟踪目标，不作为键盘接管硬门槛。2026-10-08实播截图确认：参考100%、其余站稳条件满足时，仅fr_error阻止接管；据此修正键盘接管条件。训练及批量评估的原成功判据保留。
- 超过10s未站稳则暂停并显示超时及未满足条件，等待复位；不得因超时强制切换双足教师。

### BIPED：双足教师控制

- 在同一物理状态和执行器历史上切换双足教师。
- 从过渡最后下发的FR目标恢复键盘控制，避免把目标瞬间跳到先前按键积累的高值。
- 使用双足操作盒约束后续FR目标，速度范围跟随双足教师配置。
- 本轮只有上行链路。降低FR目标不自动切回三足；返回三足通过完整复位完成。

## 3. 按键、复位与失败

- Backspace：完整复位仿真、参考时钟、保持计时和键盘目标，回到 TRIPOD。
- R：在 TRIPOD/BIPED 分别恢复相应教师默认操作目标，不改变状态；TRANSITION期间不取消起立。
- Space：沿用原暂停功能。
- 自动episode复位须同步重置状态机与键盘目标，避免新episode立刻重复触发。
- 物理失败使用原有复位路径回到三足；正常三足/双足键盘控制不沿用训练attempt的10s/24s定时结束逻辑。

## 4. 策略与接口

- 三个模型路径明确分开：现有 `--checkpoint-file` 为三足教师，新增过渡和双足模型参数。
- 当前过渡模型使用本地 `outputs/bridge_tracking_v3_recovered_20261008/model_900.pt`；双足模型使用公共坐标兼容的冻结教师。
- 三足模型可能是旧actor51或新版actor54；依据checkpoint契约构造各自输入。新版54维额外的gait/blend输入必须从运行状态提供。
- 过渡actor84和双足actor51各自构造输入，保留原关节顺序与动作零点。双足动作通过已有重基函数转换到公共执行器坐标后应用一次。
- 校验各模型的任务、输入维度、公共坐标、动作scale、关节顺序和物理接口。不能通过忽略checkpoint契约或截断输入来拼接策略。
- 键盘选择的三足教师与过渡模型训练绑定教师不同时，作为独立入口策略加载，保持过渡模型自身的训练契约校验。

## 5. 界面与记录

窗口显示当前状态、实际执行的策略、请求/下发FR高度、触发门槛、参考进度、站稳保持时间。过渡阶段显示未满足的站稳条件和失败/超时原因。

输出状态切换日志，包含仿真时间、起始高度、初速度及切换原因，便于核对键盘命令是否实际进入对应策略。

## 6. 已知效果边界

当前过渡模型训练真实入口设置为0.25–0.28m；本设计按用户要求在接近三足上限的0.33m处触发，属于不同入口分布。恢复日志的955次更新都在课程0，严格成功数为0。

状态机可提供所要求的控制链路，当前模型能否从0.33m实际起立并通过站稳门槛，仍须播放核对；不能为了展示切换而绕过站稳条件。若采用0.27m触发，则更接近现有入口配置，但与“接近三足最高点”的要求不同，需用户选择。
