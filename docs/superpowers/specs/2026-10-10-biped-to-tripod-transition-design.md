# 双足到三足过渡策略设计（待用户审核）

本轮授权范围为准备数据并提交实施计划。以下是审核后拟实施的设计，当前未修改训练任务、未执行 PPO 更新。

## 目标和方法

新增独立 `transition_down_t` / `Transition-Down-Go2-v0`，实现 `pedipulation_t → transition_down_t → loco_pedipulation_t`。目标末态为 FL/RL/RR 三足支撑，FR 悬空；不是四足全落地。

沿用当前 `transition_t` 的 BeyondMimic 参考跟踪、普通 PPO、75/192 维非对称观测、12 维位置偏移动作、ELU [256,128,128]、观测归一化、直接根状态/关节噪声、自适应失败帧采样、FR 目标限速和 0.1 权重的终点保持奖励。复用当前名义物理、噪声、奖励主项、终止阈值、50 Hz 控制/200 Hz 物理、10 秒回合及 checkpoint 校验方式。

将旧起立策略直接加载后反向执行，不会得到学习过的下降策略；改用 bridge 或教师蒸馏会改变用户指定的方法。因此采用新任务从头训练，不迁移旧正向 checkpoint，不引入新恢复奖励、控制器、相位算法或课程门槛。

## 输入与教师

使用准备目录 `outputs/biped_to_tripod_preparation_20261010/` 中的 `biped_to_tripod_reference.npz`（SHA `fa49119da56b0eb2ac2dc49d5b65dfe310aad8033a5e15565ba5079872bb11aa`）和 `biped_entry_bank.npz`（SHA `ff962e464cd928e44dea76f60363867f5361a45564ad7adbd6a43632d7193058`）。教师仅使用 `mark/biped_teacher.pt` 和 `mark/quad_teacher.pt`，两者完整 SHA 和契约见数据审核记录。

参考为同一约束 IK 方法对实测教师端点的投影，不要求投影关节角等于教师原始关节角。先保持双足 0.5 秒，下降与 FL 摆动 4.5 秒，FL 加载/COM 转移 1.5 秒，三足保持 0.5 秒；总时长 7 秒。教师仍为冻结端点与入口数据来源，不参与 PPO 梯度更新。

数据有限值、名字映射、四元数、50 Hz、几何、速度及 bank schema 已检查；运动学参考存在约 13.62 N / 3.96 N·m 的未平衡浮动基座力/矩。数据准备不是策略跟踪成功证明。

## 必须做的方向适配

1. 初始参考与末态支撑交换：RL/RR → FL/RL/RR；FR 保持离地。
2. 新策略首帧/真实入口的水平航向采用已存在的教师 `teacher_body_y_cross_up_v1`，仅对齐 XY 与该航向，保留高度、roll/pitch、速度与关节误差。原 Euler yaw 在双足竖直附近发生约 π 翻转，同一状态误差由 3.33 cm 被错误计算成 68 cm；对照已记录。
3. 终点站稳与奖励条件改为三足支撑及 FR 悬空，保持原阈值、1 秒好样本累计、前两坏样本暂停/第三坏样本清零、物理失败立即清零、原奖励公式不变。
4. 新 task/direction/支撑计划/航向定义/参考/两个教师/随机化与奖励 recipe 写入 checkpoint。正反向模型与两种对齐方式必须相互拒绝严格加载。

## 初态与真实入口

名义阶段 25% 首帧、75% 在线自适应采样。直接位姿/速度、关节噪声与当前正向范围一致；关节速度保留参考值；reference 保持不变。startup COM、共享足摩擦、encoder bias 和 actor noise 保留，不加入 push。

512 个初态评审样本中联合扰动有 15/128 个非足部穿地诊断。默认不预筛选、不缩小范围，在训练/评估报告中独立统计这些初态；如用户要求改变范围，先重生成资料并更新数据契约。

入口阶段复用现有四档课程、occupied-bin 平衡采样和 trajectory_id 分割。状态库按原物理状态恢复 root/joint/twist、实际动作经理历史和限速器状态，不授予额外 reset 宽限期。仅在参考上做 XY/教师航向对齐，不把机器人搬到参考首帧。

## 训练及资源

审核后先做 CPU 功能和 2 次 PPO 更新/checkpoint round trip，再做可用 GPU 的 8 环境 smoke。通过后拟进行 4,096 环境、seed42、30,001 次更新的从头名义训练（每 100 次保存）；随后以该新反向模型 warm start 10,000 次真实入口课程训练，保留 actor/critic/normalizer/distribution、重建优化器和课程时钟。

入口每 250 次更新评估至少 64 条独立留出轨迹，≥80% 三足站稳率连续两个窗口才晋级，规则与原任务相同。训练和评估都绑定本次审核的数据/教师/配置 SHA。当前本机无可用 CUDA，正式 GPU 资源及启动命令在审核后执行阶段确认并记录；本轮不部署或启动。

## 评估与验收

分别报告四组完整首帧（nominal/base/joints/combined）、四档真实留出入口和冻结双足→下降策略→冻结三足完整链路。首帧组每组至少 100 回合；每档入口至少 64 条不同轨迹；完整链路至少 128 条不同留出轨迹。三足教师接管后继续 3 秒，期间不 reset 或重写姿态。

交接好样本条件：参考结束，姿态误差 <0.25 rad、高度误差 <0.05 m、根线速度 <0.3 m/s、角速度 <0.8 rad/s、关节速度 norm <20 rad/s，FL/RL/RR 均有 >5 N 地面接触，FR 无接触且足中心高于 0.032 m。三足计时保持原 3 点容错规则；严格定点保持另外要求四足世界 RMS <0.06 m，并连续无中断 1 秒。

完整过渡完成率、三足保持率、严格定点率和完整教师链路率分别统计；分开记录失效原因、物理/跟踪终止、入口误差、接管瞬间状态连续性、FR 目标限速与实测速度。课程晋级不替代完整链路验收。
