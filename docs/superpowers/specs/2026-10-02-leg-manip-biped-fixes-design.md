# leg_manip 双足修复设计

用户已授权修正前一轮发现的双足问题；速度观测提议在本次先作分析。

## 高度门控

`biped_base_height` 保留每个环境的高度 score，而非全 batch 均值。现有
`_gate`、奖励权重和阈值保持原语义，逐环境广播。混合模式下成功环境的
速度/步态奖励不得依赖其他环境高度。保留先计算高度分数的奖励顺序。

## 双足退出

保留目标驱动的 mode 滞回与 0.8 s 奖励渐变，增加 episode 内的退出状态和计时。
实际 BIPED→LOCO 边沿开启退出状态，默认宽限最多 2 s。重新进入 BIPED 或
reset 清除状态。奖励权重归零、总倾角不超过 50°且至少一只前足接触地面时
提前完成退出；该判断逐环境执行，不改变 FR 的阶段机。

退出宽限期间仍限制侧倾，额外限制总倾角超过 110°的过度倾倒。宽限结束恢复
已有 LOCO 60°规则，不使用不断下降的奖励权重作为唯一安全判断。
碰撞、base_contact、landing_failed 和 episode timeout 保持有效。
退出状态是临时终止逻辑状态，不改变 actor/critic 维度或 checkpoint 网络参数。

## 验证

回归测试覆盖混合高度门控、取消/低位目标的退出边沿、计时到期、侧倾/过度倾倒、
姿态与接触确认的提前完成、重新激活、局部 reset 和环境隔离。运行 leg_manip
相关单元测试、真实 CPU 环境构建/step，再验证历史原始 checkpoint 可加载。

## 速度提议分析边界

区分 base_link 原点速度、根刚体质心速度、整机质量加权质心速度。critic 当前
已有精确锚点系 base_link 速度；加入整机 CoM 时需与当前速度奖励物理量对齐。
推荐分析 actor 小幅有界加性噪声、与命令一致的 XY 缩放和独立通道。新增输入
将影响 48D actor、131D critic、PPO 维度校验、对称变换和部署接口，本次不修改。
