# transition_t：Go2 BeyondMimic 过渡跟踪设计草案

状态：用户已审阅批准；已在当前仓库实施，验证记录见对应计划与任务 README。

## 目标与边界

新建独立任务 `transition_t`，采用 BeyondMimic 轨迹跟踪训练 Go2 从三足姿态起立到后腿双足姿态，服务于 `loco_pedipulation_t → transition_t → pedipulation_t`。本次数据只有起立方向，不能据此宣称具备反向落地能力。

使用 `outputs/teacher_endpoint_rise_clearance20mm_20261008/tripod_to_biped_reference.npz`，相对于仓库根目录解析默认路径，同时支持显式覆盖路径。该文件 SHA256 为 `1cb970ae8cfb107e25f3aca2e1d48b8cf9a2a145d6fac25c9aa67076c3bdd0b6`。

首轮实现独立可训练和可评估的过渡任务，提供保留物理状态的参考起始接口供教师切换使用。自动选择切换时机、加载冻结教师训练、反向轨迹、完整键盘 FSM 不属于首轮任务。真实教师闭环交接成功率需要训练后的独立链路评估；参考跟踪成功不等于交接成功。

## 已核实的事实

- 数据为 50 Hz、351 帧、7 秒；前 0.5 秒保持初态，0.5–2 秒转移支撑，2–5 秒起立，5–7 秒保持终态。
- 12 个关节按 FL/FR/RL/RR 的 hip/thigh/calf 排列，数据包含 `joint_names` 和 29 个 `body_names`。
- 提供关节位置/速度、刚体世界位置/四元数/线速度/角速度、根状态、四足位置和接触计划。上述跟踪数组检查为有限值。
- 初始支撑为 FL、RL、RR，末态支撑为 RL、RR；FR 全程悬空。
- 数据 README 报告动力学平衡残差最大约 13.43 N、3.20 N·m，属于运动学参考，不是已验证的物理执行结果。
- 仓库 `src/tasks/tracking/` 已有 BeyondMimic 移植，包含参考状态初始化、自适应失败帧采样、六项跟踪奖励和普通 PPO。
- 原版播放至参考末尾会重新采样并写入物理状态；这不适用于一次性过渡动作。
- 两个教师的机器人几何和动作接口有关联，但关节零点、armature 和训练随机化并非完全相同，不能宣称两者物理配置完全一致。

## 方案选择

推荐以现有 BeyondMimic 跟踪代码为基础，在 `src/tasks/transition_t/` 实现薄扩展。复用奖励和观测函数；仅扩展数据校验、参考终点处理、四足初态随机化、Go2 配置和必要的训练入口适配。

替代方案一是改造已有 `pedipulation_transition_t`，但其自定义奖励、课程和观测已明显偏离 BeyondMimic。替代方案二是沿用 `pedipulation_bridge_t` 的冻结教师训练与收集器，会带入更多状态机和训练机制。两者均不作为本次基础。

## 机器人、观测与动作

机器人沿用源教师 `loco_pedipulation_t` 的 Go2 几何、名义执行器参数和关节零点，记录实际参数。不会叠加源教师的导航奖励、命令课程和 reset 事件。

使用 canonical FL/FR/RL/RR 的 12 维关节位置偏移动作，缩放 0.25，保持教师动作到关节目标的映射。首轮关闭动作延迟，使用实际关节力矩/速度限值。

actor 保留 BeyondMimic 的当前参考关节位置/速度、参考 anchor 相对位置/6D 姿态、实际基座线速度/角速度、实际关节位置/速度和上一动作，共 75 维。critic 在此基础上增加当前身体相对位置/姿态；身体列表为 base_link 和四条腿的 thigh、calf、foot，共 13 个身体，预计 192 维。实际创建环境时断言维数及关节顺序。

参考 anchor 使用 base_link，四足跟踪使用明确的 foot body；验证 foot body 原点与参考足端 site 的关系，若存在偏置必须显式转换。基座观测直接使用机器人数据，避免依赖不匹配的 G1 sensor 名称。

所有参考关节和身体数组按名字映射到仿真实体。拒绝缺失/重复名字、错误形状、非有限值、无效四元数、非 50 Hz 数据与不匹配的控制周期，避免静默错误。

## 参考采样与轨迹终点

保留 BeyondMimic 自适应参考帧采样；默认 25% reset 从首帧开始，其余使用自适应采样，以保留完整过渡训练覆盖。自适应统计只将真实失败记为失败，超时不计入失败分布。

控制周期 0.02 秒、仿真步长 0.005 秒。参考每控制步前进一步，末帧之后保持终点，参考目标速度归零，不重新写入物理状态。episode 固定 8 秒，允许完整执行 7 秒参考并继续保持终点。随机参考起点对应的物理状态和速度必须同时初始化，禁用训练器只随机 episode 计数而不改变状态的行为。

提供独立的 `start_from_current_state(env_ids)` 语义：只建立参考坐标和时钟，不写 root/joint 状态，不清除实际速度或执行器历史。入口只对齐参考的水平平移与整体航向，保留倾角、高度、关节和速度误差。位置、姿态和世界速度目标应用同一个参考变换。

## 初始状态随机化

随机化作用于真实初始状态，目标参考保持不变。25% episode 不添加额外初态扰动，作为名义样本；该采样与参考帧选择相互独立。其余使用以下保守初值，全部可配置，最终可达范围通过 IK 后的实测状态记录。

| 变量 | 初始建议范围 |
|---|---|
| 根部 x/y 位置增量 | 每轴 ±0.02 m |
| 根部 z 位置增量 | ±0.01 m |
| 根部 roll/pitch 旋转扰动 | 每轴 ±0.08 rad |
| 根部 yaw 旋转扰动 | ±0.15 rad |
| 根部 x/y 线速度增量 | 每轴 ±0.20 m/s |
| 根部 z 线速度增量 | ±0.10 m/s |
| 根部角速度增量 | 每轴 ±0.30 rad/s |
| 四个足端 x/y 增量 | 每脚每轴 ±0.015 m |
| 悬空足端 z 增量 | ±0.01 m |
| 支撑足端 z | 保持足底接地对应的中心高度 |

先采样根位置/四元数，再在参考的水平航向坐标系内采样四足偏移。根据接触计划区分支撑脚和悬空脚，将世界足端目标转换到已扰动的机身坐标系，然后解四条腿的 IK。不以修改足端观测或目标数组代替修改真实关节状态。

IK 使用模型局部变换和关节轴构建的批量 FK/Jacobian，阻尼最小二乘迭代，受关节限位约束。检查实际足端残差、足底穿地、自碰撞和非足部穿地。对不可达样本缩小扰动重试；有限次失败后回退到对应参考初态，并记录回退率。必须保证子集 reset 不改变其他环境。

足端 IK 已承担关节位置随机化，首轮不再叠加独立关节角噪声以免破坏足端约束。关节速度沿用参考；用户此次要求的初始速度随机化施加于机身。初始速度只在 reset 写入一次。

首轮不加入新的多阶段自动课程和额外运行时强推力。若名义跟踪已稳定且当前扰动通过率不足，再依据评估逐步扩大范围，而不预先堆叠训练机制。

## 奖励与终止

保留 BeyondMimic 六项指数跟踪奖励及权重：anchor 位置/姿态各 0.5，身体相对位置/姿态和身体世界线速度/角速度各 1.0；保留动作变化、软关节限位和非期望碰撞惩罚。世界速度跟踪是参考轨迹的一部分，不增加导航速度命令。

按 Go2 尺度设置初始位置核宽：anchor/body 位置 std 为 0.15 m，姿态 std 0.4 rad，线速度 std 1.0 m/s，角速度 std 3.14 rad/s。这些是首轮参数，需用训练验证，不声称最优。

anchor 高度和足端高度误差终止阈值初值为 0.15 m；姿态使用完整四元数角误差，初值 0.8 rad。原版重力 z 分量差在后腿直立附近不足以约束整体方向。最初 0.2 秒仅暂缓跟踪误差终止；非有限状态、基座严重触地等物理失败立即结束。宽限期依据真实 reset 后步数，不能被随机 episode 计数绕过。

保留参考局部身体奖励与全局 anchor 奖励的分工；不增加新恢复奖励、残差控制器或自适应相位机制。

## PPO 与网络

actor/critic 均为 ELU MLP `[256, 128, 128]`，保留观测归一化、非对称 critic 和普通 PPO。相比 G1 的 `[512, 256, 128]`，这是针对 12 维动作和较小观测的保守起点，不能仅凭足数认定最优容量。

初值：24 步 rollout，learning_rate=3e-4，adaptive KL 调度，desired_kl=0.01，clip=0.2，gamma=0.99，lambda=0.95，entropy=0.005，5 epochs，4 minibatches，max_grad_norm=1.0，动作分布 init_std=0.5。除网络、学习率和探索幅度外保持原版主要 PPO 配置。

checkpoint 保存并校验参考哈希、关节/身体顺序、观测布局、动作零点/scale、物理参数和自适应采样统计；保持恢复训练的可复现性。
