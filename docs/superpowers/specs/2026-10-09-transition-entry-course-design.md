# transition_t 真实入口课程（用户已批准执行）

现有 `transition_t/model_30000.pt` 作为课程 0 基础。冻结 `outputs/loco_return_20261009/checkpoints/model_14999.pt`，在过渡名义物理环境中运行不同速度命令和 FR 目标，采集实际交接附近状态。保留根/关节状态、实际动作历史、实际速度、FR 相对参考首帧误差及轨迹 ID。按轨迹划分训练/留出集合；不按相邻帧随机拆分。

过渡参考保持原 351 帧与 75/192 维观测。新初始化分支恢复真实状态及公共动作坐标历史，参考从首帧开始，只对齐 XY/yaw。接触由仿真重算。原有名义首帧和自适应参考阶段初始化继续保留；目标混合比例 60% 教师状态、20% 名义首帧、20% 自适应阶段，初级课程先用 20% 教师、40% 名义、40% 自适应。

状态按实际水平速度和相对参考 FR 偏差分箱，均匀抽取已占用箱，再抽箱内样本，避免稳态重复帧主导。课程按速度/偏差上限分级，采用独立留出集合的完整起立及连续站稳率决定晋级，不使用训练 reward 或 episode 长度代替成功率。保留严格世界足端误差指标；站稳交接和严格终点分别报告。课程不会通过放宽物理失败或站稳门槛制造成功。

晋级评估优先使用不同轨迹，各窗口至少 64 条独立轨迹，站稳率至少 80%，连续两次通过。小规模状态库允许重复轨迹做运行验证，但记录实际独立轨迹数并禁止因此晋级。评估使用独立环境并保存/恢复随机数状态，不改变训练环境或原策略的归一化与运行模式。

续训从原过渡 actor/critic 和归一化状态加载；新课程计数从 0 开始，checkpoint 显式记录状态库 SHA、课程级别、采样规则和训练进度。普通播放保留原模型接口和完整物理/参考契约；新训练的初始化来源另存元数据，恢复训练拒绝不匹配的状态库。使用新输出目录，不覆盖旧模型。

实施范围包含采集器、状态库校验/恢复、课程采样、留出评估、续训脚本、回归及实际 PPO smoke、远端部署并启动一轮有界正式续训。正式训练结束后的可靠性仍需完整评估，启动成功不等于模型性能已经提高。
