# 鲁棒过渡参考跟踪修改计划

> **For agentic workers:** 使用 superpowers:executing-plans 按任务执行；用户已于2026-10-08批准实施，并要求将课程合并为三个阶段。步骤用复选框记录。

**Goal:** 让过渡策略像旧 `pedipulation_transition_t` 一样学会参考起立跟踪，再逐步覆盖真实三足教师交出的姿态、右前脚目标和初速度差异。

**Architecture:** 在 `pedipulation_bridge_t` 内恢复旧版的参考状态初始化、参考观测和分阶段跟踪课程。保留公共机器人和执行器接口，以及冻结源教师的入口生成能力；训练成功由跟踪和站稳判定，冻结双足教师接管作为独立评估。保留当前 collector 排除源教师动作的机制，避免为这次修改再开发新的 PPO 收集框架。

**Tech Stack:** Python、MuJoCo/mjlab、PyTorch、rsl_rl PPO。

---

## 1. 依据、范围和取舍

旧版 model14999 的已有评估：标准完整起点 128/128 成功；FR 多样性 128/128；阶段5混合扰动评估37/128。最终训练只到阶段1。这支持参考跟踪方法的有效性，没有证明完整鲁棒性或真实双足接管。

推荐在当前 bridge 中移植旧版训练机制，继承公共物理接口和实际源教师入口。另两个选择是直接改旧 transition（基础更接近，但仍需补公共物理接口），或先迁移旧模型（需要观测、执行器和动力学适配，首轮不采用）。

用户目标沿用：起立是唯一主要目标；FR 保留较宽松跟踪；没有导航线速度/角速度命令跟踪奖励。参考速度可以作为观测，不能因此重新加入导航奖励。

本计划只改变过渡训练和对应评估，不修改两个冻结教师、键盘控制工具或已保存旧模型。服务器训练已停止，本计划不自动启动新训练、提交或推送。

## 2. 参考数据和状态初始化

- 默认参考保留 `src/assets/motions/go2/tripod_to_biped_nominal.npz`，因为其后腿终点针对双足教师调整过。旧 `tripod_to_biped.npz` 用于对照，不混用两个资产的关节、姿态和 FR 帧。
- 使用同一参考的机身高度/姿态、九个支撑关节角及速度、机身参考速度、FL 高度和接触/卸载阶段。FR 从该参考已有 bank 选取轨迹；合并后的阶段0包含FR多样性，至少35%样本使用bank0，标准评估固定bank0。
- 当前12对 FR 路径只在后续真实入口阶段使用。FR 目标改用路径时，参考中间状态的 FR 初始关节必须通过匹配的可达目标求解，不能用另一条轨迹的 FR 关节角初始化。
- 基础阶段恢复旧分布：50%完整三足参考起点、30%起立中间帧、20%直立终点；同时初始化对应 root/joint 速度。随机航向对整个参考统一变换。
- 参考状态写入只发生在 episode reset。真实源教师入口发生在同一物理 episode 内，保留位置、姿态、速度、关节、上一动作、延迟队列及物理参数。
- 真实入口保留0.3s目标混合。姿态用四元数插值；关节参考速度、参考机身速度按混合轨迹与时间缩放一致计算，不能只混位置而沿用不匹配的速度。
- 基础时间倍率1.0；课程后期变为0.85–1.15。参考完成后保持终点，不按 FR 高度决定参考进度，不新增自适应相位算法。

## 3. 观测与初始化

过渡 actor采用旧版84维结构：公共51维 + 以下33维：

| 内容 | 维数 |
|---|---:|
| 实际高度、FR误差、参考进度 | 1+3+1 |
| 机身相对参考姿态误差 rotation vector | 3 |
| 参考高度 | 1 |
| 九个支撑关节参考位置、速度 | 9+9 |
| 机身参考线速度、角速度 | 3+3 |

冻结专家始终查询其原51维观测，过渡84维不能传给它们。复用旧版 critic172 的信息组成，按公共物理模型构造其34维物理特权字段。实际物理参数和观测必须对应。

首轮过渡 actor/critic 从头训练，使用旧版网络结构和探索配置。不把旧84维 checkpoint直接用于新的物理模型，也不继续训练当前73维 model330。新 checkpoint契约版本3记录观测布局、参考哈希、物理/动作接口、课程、奖励和终止语义。

## 4. 奖励初始配置

采用旧版明确的逐项跟踪奖励，起步配置如下。这是待训练验证的初值，不声称最优。

| 项目 | 权重 | 初始尺度/含义 |
|---|---:|---|
| orientation | 3.0 | 参考姿态误差，12°指数核；航向参考随入口统一对齐 |
| height | 3.0 | 高度误差，0.05m指数核 |
| fr_tracking | 1.0 | 位置误差平方均值，0.08m指数核；全程同尺度 |
| support_pose | 0.5 | 九个支撑关节误差平方均值，0.30rad指数核；排除FR |
| fl_height | 0.5 | 左前脚高度误差，0.05m指数核 |
| support_loss | −0.7 | 沿用旧版阶段支撑约束 |
| front_contact | −0.5 | 左前脚接触按卸载阶段加权，右前脚接地惩罚 |
| slip | −0.15 | 接触脚水平滑动 |
| excessive_force | −0.1 | 脚接触力超过160N后的归一化惩罚 |
| collision | −1.0 | 非足部触地和自碰撞；传感器不得漏掉FR |
| action_change | −0.03 | 旧版归一化：mean(((a−a_prev)*scale/0.05)^2) |
| torque | −0.02 | 按执行器限值归一化 |
| joint_limits | −0.5 | 软限位越界距离 |

不加入 linear_velocity/angular_velocity 奖励；移除当前耦合高度/重力的 `rise_progress` 和延迟双足结果±20。失败事件按一次−5计入，仍正确处理 reward乘dt。完整跟踪episode结束时尚未站稳也按任务失败−5计，不能把超时误计为成功。参考准备阶段奖励与终点奖励分别记录，以便检查是否停留低姿态获取回报。

先保持旧式指数核作为基础对照。只有基础跟踪验证失败且证据指向误差大区间时，才独立比较核宽或进展奖励，不在首轮叠加多个未经验证的奖励改动。

## 5. 训练成功和双足交接分开计数

- 跟踪成功：参考进入终点后，姿态误差<15°、高度误差<0.08m、FR误差<0.10m、前脚离地、两后脚0.3s内均有接触且当前至少一脚支撑、线速度范数<0.5m/s、角速度范数<2rad/s，连续保持1s，无物理失败。
- 持续观测站稳状态；扰动清除先前获得的成功标记，要求再次保持1s。episode最终结果不能用曾经站稳但随后倒地的标记判成功。
- 固定10s跟踪episode；基础完整起点另报告首次站稳时间，最终验收要求5s内完成上述站稳。参考中间起点和终点结果与完整起点分别统计。
- 物理失败包括基座倒地、严重非足部碰撞/自碰撞、非有限状态和严重关节越界。首轮不增加严格的参考姿态误差终止，以免提前截断需要恢复的健康状态。
- 双足交接成功：独立评估中从该策略实际站稳状态切换冻结双足教师，保留完整物理与执行器历史，按原窗口2.5s验证。报告跟踪成功但接管失败的数量。
- 静态终点初始化后交给双足教师只算终点检查，不能计为动态交接成功。

## 6. 课程

| 阶段 | 内容 | 初始分布 |
|---|---|---|
| 0 | 名义起立 + FR bank多样性；无额外扰动/随机化/噪声/延迟 | 50/30/20参考重置 |
| 1 | 时间倍率0.85–1.15 + 初始动量 + 真正站稳后的恢复扰动 | 同上 |
| 2 | 真实三足入口 + 起立中扰动 + 物理随机化/噪声/延迟 | 真实入口占比与新增扰动幅度25%→50%→75%→100%一起提高 |

参考阶段升阶以完整起点为准，不能由终点重置成功抬高。沿用至少128个完整起点结果、滚动窗口最多512、成功率≥85%、至少1500控制步的起步门槛。真实入口阶段用真实入口成功率≥85%作为提高入口比例与扰动幅度的门槛。升阶记录写入checkpoint。

阶段1动量边界为线速度增量各轴±0.12m/s、角速度±0.18rad/s；站稳后/起立中扰动最终为水平增量±0.20m/s、角速度±0.30rad/s。至少35%样本不施加额外扰动；真实源状态自然携带的速度不会清零。

阶段2沿用当前实际源教师的越界入口范围，记录启动姿态、FR误差、线/角速度。逐步加入静止和移动源；最终评估静止/移动各50%。阶段2的DR终点范围保持与当前两教师公共物理接口对应，逐项从名义值扩展；不能复制旧版写死40/1增益的随机化函数到公共模型。

PPO首轮：init_std=0.5、learning_rate=3e-4、entropy_coef=0.005、gamma=0.995、lambda=0.95。记录每关节std及关节目标噪声；若std持续增大同时成功下降，暂停该轮分析，不以运行轮数替代收敛证据。

## 8. 验收建议

- 标准完整起点与FR多样性：各3个种子×128次，成功率≥95%；平均FR误差≤0.05m。
- 最终规定范围内的真实入口和扰动：各3个种子×128次，5s内连续站稳1s成功率≥90%；FR RMS≤0.10m；静止/移动与初速度分组分别报告。
- 真实双足接管：同样3个种子×128次，完整源→过渡→双足链路成功率目标≥90%，另报告源产出率及源成功条件下的接管率。
- 所有比例按完整尝试统计，并报告各种子结果与95%置信区间。阈值是验收目标，不是对训练结果的预测；范围外不宣称鲁棒。
